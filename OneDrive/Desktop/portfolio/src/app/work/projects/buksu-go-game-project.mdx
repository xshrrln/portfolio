## Overview

BukSU GO is a game project created during my earlier academic years. It focused on designing a playful, interactive experience inspired by campus life and exploration.

## Purpose

The project helped me explore game logic, creative interaction, and how to translate ideas into an engaging user experience.

## Key Highlights

- Game design concepts
- Interactive student-focused experience
- Creative storytelling through gameplay
- UI and visual direction

## Outcome

This project allowed me to explore design and programming in a more playful way while still building useful creative and technical skills.
