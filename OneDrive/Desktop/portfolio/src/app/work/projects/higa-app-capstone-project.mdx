## Overview

Higa is my capstone project and the most recent academic work in my portfolio. It focuses on preserving and promoting the Higaonon language through a mobile application that supports translation, vocabulary access, and learning.

## Goal

The goal of the project is to make the language more accessible to younger generations while also supporting cultural preservation through digital tools.

## Key Features

- English-to-Higaonon translation
- Digital dictionary and learning support
- Audio pronunciation assistance
- Offline accessibility for language learning

## Outcome

This project represents the most advanced academic work in my timeline and reflects my interest in technology, design, and cultural impact.
