## Overview

This project was developed as a web system focused on managing inventory and related records for a campus office. I worked on creating a more organized and efficient way to track materials and transactions.

## Goal

The goal was to simplify inventory management and provide a usable digital system that reduces manual work and improves accessibility.

## Key Features

- Inventory tracking
- Record management
- User-friendly dashboard
- Organized data handling

## Outcome

This project helped me strengthen my understanding of system design, data organization, and building practical digital solutions for real-world needs.
